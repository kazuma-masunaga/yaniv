# ヤニブ（Yaniv）ブラウザ版

トランプゲーム「ヤニブ」を、素の HTML/CSS/JavaScript だけで遊べるアプリです。ビルド工程はなく、`index.html` / `engine.js` / `net.js` の 3 ファイルを静的ホスティング（GitHub Pages など）に置くだけで動きます。

## 遊び方（3 つのモード）

ロビーで入口を選びます。

| 入口 | 内容 |
| --- | --- |
| **この端末で遊ぶ** | 1 台の端末で、人間 1 人以上 + CPU を混ぜて 2〜5 人。人間が 2 人以上なら自動でパス＆プレイ（手番ごとに「端末を渡してください」の画面が出る）。 |
| **部屋を作る** | 名前を入れて「部屋を作る」。6 文字の部屋コードと共有 URL が表示されるので、友だちに送ります。人数枠（2〜5）・ジョーカー・脱落ライン・CPU の強さを決め、参加者がそろったら「開始」。空席は CPU で埋まります。 |
| **部屋に参加** | 共有 URL を開く（コードが入力済みになる）か、部屋コードと名前を入れて「参加」。ログインは不要です。ホストが開始するまで待機画面でロビーをミラー表示します。 |

対局画面は 3 モード共通です。オンライン時は自分の手番以外はボタンが無効になり、他プレイヤーに「接続中 / 切断中」のバッジが付きます。ラウンド結果・ゲーム終了画面で「次のラウンド」「もう一度」を押せるのはホストだけで、参加者には「ホストを待っています」と表示されます。

### ルールの要点
- 各 5 枚配り、山札の 1 枚を捨て札にして開始。A=1、2〜10 はそのまま、J/Q/K=10、ジョーカー=0 点。
- 手番では「ヤニブ宣言（手札合計 7 点以下）」か「1 組捨てて 1 枚引く」。捨てられる組は 1 枚 / 同ランク 2 枚以上 / 同スートの連番 3 枚以上（ジョーカーは連番のワイルド）。
- 引くのは山札か、直前の人が捨てた組のカード（連番は両端のみ）。
- ヤニブ宣言で全員公開。宣言者と同点以下の人がいれば「ヤニブ返し」（宣言者 +30 点、返した人 0 点）。
- 累計が脱落ライン以上で脱落。最後の 1 人が勝ち。

## 部屋の仕組みと制約

- 通信は **PeerJS（WebRTC）による P2P** です。状態を持つのは **ホストだけ**（ホスト権限方式）。参加者は「手」をホストに送り、ホストが検証して進め、各参加者には「その人から見える状態」だけを配信します。他人の手札や山札の中身は参加者の端末に届きません。
- **ホストがタブを閉じると部屋は終了します。** ホスト画面には常にその注意が表示されます。参加者には「部屋は終了しました」と表示されます。
- 参加者側の接続が切れた場合は自動で再接続（2 秒 → 4 秒 → 8 秒 … 最大 30 秒間隔）を続け、同じ席に戻ります。席の情報は `localStorage` に保存されるので、ページを再読み込みした後にもう一度「参加」を押せば同じ席に戻れます。切断中の人の手番になったら、ホストは「CPU に交代」でその席を CPU に替えられます。
- **PeerJS の公開シグナリングサーバー（0.peerjs.com）に依存します。** 部屋コードの解決と接続の確立にだけ使い、ゲームのデータは端末同士で直接やり取りします。公開サーバーが混雑・停止していると部屋を作れない／参加できないことがあります。企業ネットワークなど WebRTC が通らない環境では接続できない場合があります（STUN のみ、TURN は未設定）。
- 部屋コードは 6 文字（0/O/1/I/L を除く英大文字と数字）。PeerJS 上の ID は `yaniv-<部屋コード>` です。

## ローカルで開く

`file://` で直接開いても「この端末で遊ぶ」は動きますが、オンライン対戦（PeerJS の読み込みと `?room=` 付き URL）は HTTP 経由で開いてください。

```sh
cd yaniv
npx serve .          # または: python3 -m http.server 8080
# http://localhost:3000 （serve の場合）を開く
```

複数端末で試すには、同じ LAN 上の端末から `http://<このPCのIP>:3000` を開くか、GitHub Pages に公開して共有 URL を使ってください（WebRTC は `https` か `localhost` でないと動かないブラウザがあります）。

## 公開手順（GitHub Pages）

1. `index.html` / `engine.js` / `net.js` をリポジトリに置く（`tests/` はあっても問題ありません）。
2. GitHub のリポジトリ設定 → Pages → Branch を `main`（ルート）にして保存。
3. 表示された URL（`https://<user>.github.io/<repo>/`）を開く。「部屋を作る」で出る共有 URL はこの URL を元に生成されます。

## 開発

```sh
node --test tests/     # engine.test.js + net.test.js（PeerJS 不要。インメモリトランスポートで通信層をテスト）
```

- `engine.js` … ゲームロジック。決定論的（乱数は引数で注入）、状態は plain object。
- `net.js` … 部屋・ホスト権限・再接続のロジックと、トランスポート抽象（PeerJS 実装 / テスト用インメモリ実装）。
- `index.html` … UI。`engine.js` を判定表示に、`net.js` を通信に使います。
